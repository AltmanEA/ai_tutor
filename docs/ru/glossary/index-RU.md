Канонические предметные термины проекта ai_tutor. Авторитетна английская
форма; русская форма ведёт переводное зеркало
(`docs/ru/glossary/index-RU.md`).

## 1. Знание

- **sense** (смысл) — Информация, содержащая элементы и связи между
  ними, помещающаяся в рабочую память мозга человека.
- **concept** (понятие) — Единица знаний, объединяющая несколько смыслов
  одной сущности, обозначаемая на языке с помощью термина.
- **term** (термин) — Словесное обозначение понятия в языке.
- **name** (имя) — Уникальный идентификатор атома, термина или смысла
  в рамках курса.

## 2. Структура учебных материалов

- **atom** (атом) — Минимальная единица учебного материала: определение,
  пример или задание.
- **definition** (определение) — Атом, вводящий термин и главный смысл
  понятия.
- **example** (пример) — Атом, иллюстрирующий применение термина.
- **assignment** (задание) — Атом, предлагающий студенту выполнить
  практическую работу для закрепления или проверки смысла.
- **topic** (тема) — Раздел лекции, содержащий несколько сегментов.
- **segment** (сегмент) — Часть темы — группа атомов, одна порция
  нового материала на шаге объяснения.
- **lecture** (лекция) — Файл учебных материалов; верхний уровень
  иерархии, состоит из тем.

Иерархия материала: лекция → тема → сегмент → атом.

## 3. Связи

- **link** (связь) — Направленное указание одного атома на другой,
  выражающее смысловую зависимость между ними.
- **refines** (уточняет) — Тип направленной связи (связь «уточнения»),
  при котором новое понятие (обозначенное новым термином) вводится
  путём добавления уточняющего смысла к исходному понятию.
- **extends** (расширяет) — Тип направленной связи (связь «расширения»),
  при котором к существующему понятию добавляется новый смысл (со своим
  уникальным именем в пространстве имён) без введения нового термина.
- **requires** (опирается) — Тип направленной связи (связь «опора»),
  указывающий, что для понимания данного определения необходимо
  предварительное понимание целевого термина (понятия).

## 4. Учебный процесс

- **progress** (прогресс) — Зафиксированное состояние усвоения (уровень
  владения) каждого смысла конкретным студентом, отслеживаемое во
  времени с учётом динамики памяти.
- **lesson** (занятие) — Непрерывный отрезок учебного процесса, в
  течение которого студент изучает определённый объём материала;
  состоит из последовательности шагов.
- **step** (шаг) — Минимальная единица учебного процесса, в рамках
  которой события прогресса фиксируются однократно.

## 5. Роли

- **Professor** (Профессор) — Человек; задаёт концепцию и методику
  преподавания, основное содержание курса; авторитет над учебной
  программой, может вмешаться в любой момент.
- **Docent** (Доцент) — ИИ-агент; выступает учителем во время обучения:
  объясняет, формирует задания и проверки, контролирует усвоение и
  корректирует программу под надзором Профессора.
- **Assistant** (Ассистент) — ИИ-агент; помогает Профессору в
  подготовке материалов: черновики определений, примеров, заданий,
  примерный порядок изучения.
- **Technician** (Лаборант) — Программа; выполняет хорошо
  алгоритмизируемые задачи в помощь Ассистенту и Доценту.

## 6. Проекты и участники

- **Core Project** (Проект ядра) — Также «Ядро» / Core: репозиторий и
  набор артефактов, определяющих методологию преподавания и
  инструменты обучения.
- **Learning Project** (Учебный проект) — Целевой проект (рабочая
  директория курса), в который развёрнуты компоненты Ядра и в котором
  хранятся учебные материалы и данные о прогрессе студента.
- **Student** (Студент) — Человек, изучающий учебные материалы курса;
  субъект, для которого ведётся учёт прогресса.
